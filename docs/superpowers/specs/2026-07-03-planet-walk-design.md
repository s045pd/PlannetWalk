# 《星球漫步》(Planet Walk) 设计文档

**日期**: 2026-07-03
**状态**: 已确认
**类型**: 纯前端 3D 游戏（零后端，静态部署）

## 概述

一款在「被毁灭的世界」的行星地表上进行拟真级漫步的氛围探索游戏。玩家以第一人称宇航员视角，在无边际的程序生成地表上徒步或驾驶载具穿行，探索坍塌的未来都市废墟，体验完整的日夜循环、动态天气与真实物理。

**核心体验定位**：氛围探索步行模拟（参考 Journey / Death Stranding 的探索质感）——漫步与驾驶本身就是乐趣，无生存压力、无战斗。所有技术资源集中投入画面拟真感与氛围。

## 已确认的设计决策

| 决策点 | 结论 |
|--------|------|
| 核心定位 | 氛围探索步行模拟 |
| 世界结构 | 广袤行星地表（无边际程序生成 + 天穹系统） |
| 视角 | 第一人称（宇航员头盔视角），无角色模型 |
| 渲染基线 | Three.js + WebGL2 |
| 物理引擎 | Rapier3D (WASM) |
| 架构 | Vite + TypeScript，纯 three.js 驱动渲染循环，不用 UI 框架协调器 |
| 载具 | 六轮探测车 + 低空悬浮飞行器 + 喷气背包（全部三种） |
| 废墟风格 | 坍塌的未来都市 |

## 1. 总体架构

**技术栈**：Vite + TypeScript + Three.js (WebGL2) + `@dimforge/rapier3d-compat`（WASM 物理）。HUD 用轻量 DOM 覆盖层。零后端，构建产物为纯静态文件。

**模块划分**（按领域组织）：

```
src/
├── core/       # 引擎循环（固定物理步长 + 可变渲染帧插值）、事件总线、输入管理、资源加载
├── world/      # 地形生成、区块流式加载、废墟城市生成、散布物
├── sky/        # 大气散射、日夜循环、星空、行星环碎带
├── weather/    # 天气状态机、GPU 粒子、风场
├── physics/    # Rapier 封装、角色控制器、重力配置
├── player/     # 第一人称控制器、相机、头部晃动
├── vehicles/   # 探测车、悬浮飞行器、喷气背包（统一乘载接口 Rideable）
├── fx/         # 后处理管线、粒子特效
├── hud/        # 头盔 HUD（DOM 覆盖层）
└── audio/      # 风声、脚步、引擎、环境音（WebAudio）
```

**数据流**：单向 `输入 → 物理步进(60Hz 固定) → 游戏逻辑 → 渲染(插值)`。系统间通过事件总线通信（如 `weather:changed`、`vehicle:entered`），不互相直接引用。

**错误处理**：WebGL 上下文丢失监听并提示恢复；Rapier WASM 加载失败给出降级提示页；worker 生成失败重试并记录 console 上下文。

## 2. 地形系统（世界构建）

- **无边际程序生成**：四叉树 LOD 分块地形（chunk），高度场由 fBm 噪声 + domain warping + ridged 噪声叠加，形成山脊、陨击盆地、干涸河床。
- **Web Worker 生成**：几何体（顶点/法线/索引）在 worker 中构建，主线程只做 GPU 上传，行走中新区块加载不掉帧。
- **生物群系**：尘漠、碎岩原、玻璃化熔壳带（轨道武器灼烧痕迹）、灰烬平原。由低频噪声划分，边界渐变。
- **地表材质**：splat 混合，按坡度/高度混合沙、岩石、灰烬、熔渣四层纹理（程序生成或 CC0 纹理）。
- **浮点精度**：floating origin——玩家远离原点超过阈值时整体世界坐标回移，支持无限漫游无抖动。
- **碰撞**：仅玩家周围 3×3 区块生成 Rapier heightfield collider，随移动增删。

## 3. 天穹与光照

- **物理大气散射**：Rayleigh + Mie 单次散射的天穹 shader，日出日落色彩由太阳角度实时计算，不使用静态天空贴图。
- **日夜循环**：太阳/残月方向驱动 DirectionalLight、环境光强度、曝光值；夜间星空 + 银河纹理淡入。
- **行星环碎带**：天空中一条被摧毁卫星形成的碎片环（半透明弧带 + 近处碎块），是「被毁灭世界」的永恒视觉印记，白天隐约可见、夜间清晰。
- **阴影**：级联阴影贴图（CSM），近处高精度。
- **雾**：高度雾 + 距离雾，与天气系统联动。
- **后处理**：ACES 色调映射、bloom、SSAO、vignette、镜头尘埃颗粒。

## 4. 天气系统

天气状态机，7 种状态，转换时所有参数（雾密度、风力、光照色温、粒子发射率、音量）在 10–30 秒内插值过渡：

1. **晴朗** — 基准状态
2. **扬尘** — 低空尘霾、能见度中等
3. **沙尘暴** — 遮天蔽日、狂风音效、能见度极低、天光转橙褐
4. **酸雨** — 雨幕粒子、地表湿润反光增强、雨声
5. **雷暴** — 酸雨 + 闪电（天空闪光 + 方向光脉冲 + 按距离延迟的雷声）
6. **灰烬飘落** — 缓慢黑灰色雪状粒子、末日静谧氛围
7. **浓雾** — 能见度压缩、轮廓剥离

- 粒子全部 GPU 化（instanced points/quads + 顶点 shader 位移），风场统一影响粒子漂移方向与环境音。
- 天气随游戏时间按马尔可夫链自动演化；提供调试面板手动切换。

## 5. 物理（Rapier）

- 固定 60Hz 物理步进，渲染帧插值，保证不同刷新率下手感一致。
- **重力**：可配置行星重力，默认 0.7g——微低重力的跳跃与坠落手感。
- **玩家**：Rapier 运动学角色控制器（胶囊体），支持斜坡、台阶、滑落。
- **探测车**：6 轮 raycast vehicle 独立悬挂——悬挂压缩视觉反馈、扬尘粒子、可翻滚。
- **悬浮飞行器**：动力学刚体 + 四角向下射线的 PID 悬浮控制，倾斜转向，限制低空飞行（离地上限）。
- **喷气背包**：角色控制器叠加垂直/方向冲量，燃料槽消耗与自动缓慢回充，低重力下有滑翔感。

## 6. 废墟都市（建筑）

- **程序化坍塌楼宇**：参数化楼体（层数/占地/退台）+ 破坏算法：断层切割、整体倾斜倒塌、楼板外露、顶部缺角。混凝土、锈蚀钢架、碎玻璃幕墙三类材质。
- **城市遗迹区散布**：低频噪声决定城市区块位置；区块内保留网格街道残迹，楼宇密度从区块中心向外衰减。
- **小型散布物**：集装箱、倾倒灯柱、废弃车辆残骸、碎石堆，全部 InstancedMesh 批量渲染。
- **碰撞**：建筑用简化盒体组合，部分残骸可步行进入。
- 生成完全确定性（种子驱动），同一种子每次进入世界一致。

## 7. 载具系统

统一 `Rideable` 接口：`enter() / exit() / update(dt) / getCamera()`。靠近载具按 E 进入，进入后输入路由、相机与 HUD 切换到载具模式。

| 载具 | 特性 |
|------|------|
| 六轮探测车 | 独立悬挂、前灯（夜间照明）、车轮扬尘、引擎音、翻滚后可复位 |
| 悬浮飞行器 | PID 悬浮、倾斜转向、推进器辉光、限高低空飞行 |
| 喷气背包 | 随身装备无需进入、按住跳跃键持续喷射、燃料 HUD、喷焰粒子 |

## 8. 玩家体验与 HUD

- PointerLock 第一人称：WASD 移动、Shift 奔跑、Space 跳跃/喷射、E 交互。
- 沉浸细节：头部晃动（行走/奔跑频率不同）、依地表材质变化的脚步声、头盔内呼吸声、头盔音频低通滤波。
- **头盔 HUD**（DOM）：准星、罗盘条、速度/高度计、喷气燃料条、天气警报、星球时间。载具模式显示对应仪表。
- 开场：简短的着陆序列（黑屏渐亮 + 舱门开启视角）直接入世界，无菜单堆砌。

## 9. 性能预算与画质分级

- 目标：桌面 Chrome 60fps @1080p；draw call < 500；三角形 < 200 万。
- 画质三档（低/中/高）：阴影分辨率与级联数、粒子数量、SSAO/bloom 开关、地形视距。
- 纹理与几何全部程序生成或轻量 CC0 资源，总资源体积目标 < 15MB。

## 10. 测试策略

- **单元测试（Vitest）**：纯逻辑模块——噪声与高度场函数（确定性）、天气状态机转换、LOD 选择逻辑、载具参数计算（悬浮 PID、燃料）、floating origin 坐标回移。
- **视觉冒烟（Playwright）**：场景加载无 console 错误、关键状态截图（白天/夜晚/沙尘暴/城市废墟/各载具）、fps 采样阈值断言。
- 图形渲染代码以视觉回归为主信号，不做脆弱的渲染内部断言（遵循 web 测试规则）。

## 非目标（明确不做）

- 生存系统（氧气/温度/资源采集）
- 战斗、NPC、敌人
- 多人联机
- 移动端触控适配（首版仅桌面键鼠）
- 真球形行星（地表为平面大世界 + 天穹）

## 构建顺序建议（供实施计划参考）

1. 项目骨架 + 引擎循环 + 第一人称控制器（灰盒地面）
2. 程序地形 + LOD + worker 流式加载 + floating origin
3. 天穹（大气散射 + 日夜循环 + 星空/碎片环）+ 光照 + 后处理
4. 物理接入（Rapier 角色控制器 + 地形碰撞）
5. 天气系统
6. 废墟都市生成
7. 三种载具
8. HUD + 音频 + 沉浸细节打磨
9. 性能分级 + 测试补全
