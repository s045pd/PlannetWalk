# Planet Walk — 星球漫步

纯前端拟真级星球漫步游戏：第一人称宇航员视角，漫步在一颗被毁灭的行星地表——无边际程序生成地形、坍塌的未来都市废墟、完整日夜循环、动态天气与真实物理载具。零后端，构建产物为纯静态文件。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run test       # Vitest 单元测试（纯逻辑模块）
npm run test:e2e   # Playwright 视觉冒烟（首次运行需 npx playwright install chromium）
```

## 技术架构

- **渲染**: Three.js (WebGL2) + pmndrs postprocessing（bloom / ACES / SMAA / 暗角 / 颗粒）
- **物理**: Rapier3D (WASM)，固定 60Hz 步进 + 渲染插值；0.7g 行星重力
- **地形**: 环形 LOD 区块（128m），fBm + domain warping + ridged 噪声高度场，双 Web Worker 流式生成，floating origin 无限漫游
- **天穹**: Rayleigh + Mie 单次散射 shader（CPU 同构采样驱动雾色），日夜循环、星空银河、行星环碎带
- **天气**: 7 态马尔可夫状态机，参数全插值过渡；GPU 粒子（雨/尘/灰烬）；闪电 + 延迟雷声
- **废墟**: 程序化坍塌楼宇（参差墙条/倾斜/碎石堆），城市站点哈希网格 + 地形台地混合，就近物理碰撞
- **载具**: 六轮 raycast vehicle 探测车、四点 PID 悬浮飞行器、喷气背包（燃料系统）
- **音频**: 全程序化 WebAudio（风/脚步/呼吸/引擎/雷/雨），头盔低通总线
- **HUD**: DOM 覆盖层（罗盘带/速度高度/燃料/天气警报/时间）

世界生成完全由种子决定（`src/main.ts` 中 `SEED`），同一种子每次进入世界一致。

## 测试策略

纯逻辑模块（噪声、高度场、天气机、PID、燃料、原点回移、固定步长）用 Vitest 单测；渲染层用 Playwright 截图基线做视觉回归（白天城市天际线/黎明/夜晚星环/沙尘暴/灰烬街景），不做脆弱的渲染内部断言。
