# Planet Walk — 星球漫步

纯前端拟真级星球漫步游戏：第一人称宇航员视角，漫步在一颗被毁灭的行星地表——无边际程序生成地形、坍塌的未来都市废墟、完整日夜循环、动态天气与真实物理载具。零后端，构建产物为纯静态文件。

天上的碎片环是被轨道武器击碎的卫星「晨昏」。在废墟与荒原间散落着 17 块数据板，拼出这个世界毁灭的经过。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 生产构建
npm run test       # Vitest 单元测试（纯逻辑模块）
npm run test:e2e   # Playwright 视觉冒烟（首次运行需 npx playwright install chromium）
```

## 世界与系统

- **信号追踪主线**：头盔收到方舟七号的重播信号，HUD 信号强度引导你走完 5 级中继链，终点是方舟九号发射台遗址
- **收集结局**：集齐全部 17 条日志触发一次性结局事件（极光 + 方舟回信 + 碎片环增亮）
- **叙事碎片**：城市与 POI 处散落发光数据板，拾取后打字机呈现日志（进度自动存档）
- **兴趣点 (POI)**：坠毁船残骸 / 信标塔 / 环碎片陨坑 / 光环试炼场，罗盘显示最近 POI 方位与距离
- **测绘塔**：登上信标塔顶自动测绘——地图点亮 2km 揭示圆 + 扫描冷却减半 30 分钟
- **全息地图**：探索即填图，只显示走过与测绘过的区域（高度灰阶 + 全部标记）
- **光环试炼**：驾悬浮器穿起点门开始计时，顺序穿过 8 个光环；最佳成绩持久化，重跑时有幽灵回放
- **载具能量**：驾驶耗电、白天太阳能回充（充速低于耗速）、空电失去动力——白天远征、停车充电的节奏
- **夜间低温**：夜里露天行走面罩逐渐结霜并减速，躲进车内/屋檐下或等日出恢复（无死亡惩罚）
- **可进入建筑**：约 1/4 的废墟楼宇有门洞与空腔大堂，内部平台可逐级跳上
- **可推动残骸**：城市街道上的集装箱与车壳是真实刚体，开车撞飞它们
- **夜间城市微光**：少数楼宇残留的应急灯在夜里忽明忽暗
- **天气影响玩法**：沙尘暴逼近有 HUD 倒计时，室外会被狂风推移、罗盘失灵，躲进掩蔽处风声骤闷；雷暴中高空飞行或喷射会引来近距雷击（击退 + 燃料损失）
- **存档**：位置/时间/天气/日志/任务/测绘/信标/载具状态每 10 秒自动保存（localStorage），刷新续玩

## 技术架构

- **渲染**: Three.js (WebGL2) + pmndrs postprocessing（bloom / ACES / SMAA / 暗角 / 颗粒）+ n8ao SSAO
- **物理**: Rapier3D (WASM)，固定 60Hz 步进 + 渲染插值；0.7g 行星重力
- **地形**: 环形 LOD 区块（128m），fBm + domain warping + ridged 噪声高度场 + 程序细节法线，双 Web Worker 流式生成，floating origin 无限漫游
- **天穹**: Rayleigh + Mie 单次散射 shader（CPU 同构采样驱动雾色），日夜循环、星空银河、行星环碎带、极光帘幕
- **天气**: 8 态马尔可夫状态机，参数全插值过渡；GPU 粒子（雨/尘/灰烬）；闪电 + 延迟雷声
- **废墟**: 程序化坍塌楼宇（参差墙条/倾斜/碎石堆/可进入大堂），城市站点哈希网格 + 地形台地混合，单刚体多碰撞盒
- **载具**: 六轮 raycast vehicle 探测车（车轮扬尘）、四点 PID 悬浮飞行器（气垫尘环）、喷气背包（燃料 + 喷焰）
- **音频**: 全程序化 WebAudio（风/脚步/呼吸/引擎/雷/雨），头盔低通总线
- **HUD**: DOM 覆盖层（罗盘带/POI 信标/速度高度/燃料/天气警报/时间/日志打字机/面罩质感）

世界生成完全由种子决定（`src/main.ts` 中 `SEED`），同一种子每次进入世界一致。

## 测试策略

纯逻辑模块（噪声、高度场、POI 选址、天气机、PID、燃料、日志分配、存档序列化、原点回移、固定步长）用 Vitest 单测；渲染层用 Playwright 截图基线做视觉回归，不做脆弱的渲染内部断言。
